<p align="left">Somos desarrolladores de CUCEI con el objetivo de crear un ecosistema estudiantil a prueba de LEO.<br><br>Para esto ofrecemos infraestructura que te permite a ti estudiante desarrollar aplicaciones encima de esta. Proveemos un sistema de autenticación único que permite que tus usuarios puedan usar su  cuenta de LEO para iniciar sesión en tu aplicación, proveemos interacciones con LEO.<br><br>Todo esto acompañado de un sistema de traza, el cual mantiene un registro del acceso a la información, permitiendo que el usuario pueda conocer en todo momento quien hace uso de sus datos y revocar el acceso a estos si el usuario lo decide.</p>

<p align="left">Trabajamos con las tecnologías más eficientes con el objetivo de lograr bajos tiempos en el acceso a la información.<br><br>Para esto decidimos cambiar el runtime de Javascript de NodeJS a Bun, lo que nos resulto en mejores tiempos de respuesta y soporte de Typescript.<br><br>Gracias a Typescript hemos logrado que los modulos de comunicación con Leo esten fuertemente tipados, lo que nos da una seguridad en tiempo de producción mayor, además de una mejor experiencía de desarrollo.<br><br>Tambien hemos construido nuestras capas de comunicación y abstracción siguiendo una Clean Architecture, producto de esto se decidio separar el proyecto en varios microservicios, todos estos unidos por el paquete `@leones/safari`, el cual sirve como punto común para dominios, responses y requests.</p>
